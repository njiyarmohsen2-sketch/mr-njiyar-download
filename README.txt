# Mr. Njiyar APK Download Website

This package contains:
- index.html — the download webpage
- Mr-Njiyar.apk — the Android APK

To publish:
1. Upload both files to the same folder on a static web host.
2. Open the URL for index.html.
3. Users can click "Download APK" to download the application.

Important:
The APK must be hosted on the same website/domain or otherwise made publicly accessible.
